Chemistry-Specific Terminology
| Source | Description    |Checked |Recommended | 
|:---|:---|---|---|
| **[IUPAC Gold Book](https://goldbook.iupac.org/)**                         | Official IUPAC definitions of chemical terminology. Highly authoritative. |YES |YES |
| **[ChEBI](https://www.ebi.ac.uk/chebi/)**                                  | Chemical Entities of Biological Interest — ontology of molecular entities focused on 'small' chemical compounds. |
| **[PubChem Compound](https://pubchem.ncbi.nlm.nih.gov/)**                  | NCBI’s database of chemical molecules and their activities — includes standardized identifiers.                  |
| **[CAS Registry (SciFinder)](https://www.cas.org/)**                       | Chemical Abstracts Service, provides unique CAS numbers for chemicals. Closed-access but industry-standard.      |
| **[NIST Chemistry WebBook](https://webbook.nist.gov/)**                    | Reference data on chemical thermodynamics and spectra.                                                           |
| **[InChI / InChIKey](https://www.inchi-trust.org/)**                       | Canonical textual identifiers for chemical substances. Used globally in cheminformatics.                         |
| **[RSC Ontologies](https://www.rsc.org/)**                                 | Royal Society of Chemistry – various publications and vocabularies.                                              |
| **[ChemOnt](https://github.com/wnelson/ChemOnt)**                          | Chemical ontology for classification (used in ClassyFire).                                                       |
| **[MeSH (Chemicals & Drugs)](https://www.nlm.nih.gov/mesh/meshhome.html)** | Controlled vocabulary from the National Library of Medicine — includes biochemical substances.                   |


Life Sciences & Bioinformatics
| Source | Description    |Checked |Recommended | 
|:---|:---|---|---|
| **[Gene Ontology (GO)](http://geneontology.org/)**                            | Classifies gene products by function, location, and process.              |
| **[UniProt](https://www.uniprot.org/)**                                       | Protein knowledgebase — includes terms for structure, function, pathways. |
| **[OBI (Ontology for Biomedical Investigations)](https://obi-ontology.org/)** | Defines types of assays, protocols, materials, etc.                       |


Cross-Domain / General Vocabularies
| Source | Description    |Checked |Recommended | 
|:---|:---|---|---|
| **[schema.org](https://schema.org/)**             | Structured data vocabulary used by web platforms. Covers product data, events, creative works, etc. | YES |YES |
| **[Dublin Core](https://www.dublincore.org/)**    | Metadata vocabulary for describing resources (title, creator, date, etc.)                           |
| **[GS1](https://www.gs1.org/voc)**                | Industry-standard vocab for product IDs, packaging, logistics (used in barcodes, GTINs, etc.)       | YES |YES |
| **[QUDT](http://qudt.org/)**                      | Ontology for physical quantities and units. Ideal for measurement-heavy domains.                    |
| **[UN/CEFACT](https://unece.org/trade/uncefact)** | United Nations standard for trade and logistics terminologies.                                      |YES |YES |
| **[LOINC](https://loinc.org/)**                   | Laboratory and clinical terminology for test results and observations.                              |

|:---|:---|---|---|

Other Notable Sources
